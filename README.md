# Site Halcyon Conseil

Site statique (HTML/CSS/JS, aucune dépendance). Fichiers : index.html, favicon.svg, assets/.

## Avant de publier
1. Formulaire : créer un compte gratuit sur formspree.io, créer un formulaire, puis remplacer `VOTRE_ID_FORMSPREE` dans index.html par votre identifiant.
2. Pied de page : remplacer `[À COMPLÉTER]` par votre numéro SIRET et créer une page Mentions légales.
3. Vérifier l'accord de vos clients pour l'affichage de leurs logos et des plans/vues 3D.

## Publier sur GitHub Pages
1. Créer un dépôt (ex. halcyon-conseil) et y déposer tous les fichiers à la racine.
2. Settings > Pages > Deploy from a branch > main / (root).
3. Le site est en ligne sur https://<compte>.github.io/halcyon-conseil/
